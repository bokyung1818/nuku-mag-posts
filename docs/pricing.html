프리랜서 단가 가이드

후배가 "얼마 받아요?" 물으면 뭐라 답하세요?

단가는 감이 아니라 '구조'로 정합니다. 빠지면 손해 보는 항목들.
한눈에
  • 단가 = 작업비 + 장비 + 사용범위 + 권리처리
  • '하루 얼마'만 보면 손해 — 통째로 무료가 되는 항목이 많다
  • 매절(전부 양도)과 회차·기간 한정 사용은 값이 달라야 한다
  • 깎이지 않으려면 견적을 '항목'으로 쪼개라

'하루 얼마'가 위험한 이유

인건비만 떠올리면 장비·후반작업·사용범위·권리가 전부 공짜로 딸려가요. 같은 촬영도 어디에 얼마나 오래 쓰이느냐에 따라 값이 달라야 정상입니다.

단가에 들어가야 할 항목

  • 작업 일수·시간, 준비·이동 시간
  • 장비·소모품(렌탈 포함)
  • 후반작업 — 편집·색보정·사운드
  • 수정 횟수 (무제한 수정은 금물)
  • 사용 매체·기간·지역
  • 2차 사용 / 매절(전부 양도) 여부
  • 긴급·야간·주말 할증

매절이냐, 빌려주는 거냐

권리를 통째로 넘기는 것과 정해진 범위만 빌려주는 건 완전히 다른 거래예요. 이걸 구분 안 하면 헐값에 평생 권리를 넘기게 됩니다. (자세한 건 '매절' 편 참고)

한 번 찍고 전 매체·무기한으로 쓰이면(매절) 값이 훨씬 높아야 정상. 특정 매체·기간만 쓰면 더 낮게.

깎이지 않는 견적의 기술

항목별로 쪼개서 제시
'올인 하루 ○○' 대신 작업/장비/후반/사용권을 분리.
수정 횟수를 못 박기
'2차 수정까지 포함, 이후 회당 ○○'.
사용 범위를 적기
어느 매체에 얼마 동안 쓰는지 명시.
확장은 추가 비용
매체·기간 늘면 별도 정산 조항.

한 가지 현실

공식 '표준 단가표'는 없어요. 분야·경력·지역마다 시세가 다릅니다. 동료·협회 시세를 참고하되, 먼저 내 원가(시간·장비·기회비용)부터 계산해 바닥선을 정하세요. 문체부 표준계약서의 '사용범위·2차 사용 보상' 개념도 협상 근거가 됩니다.

안내 · 단가는 시장과 협상의 영역이라 정해진 정답이 없습니다. 본 자료는 항목을 빠뜨리지 않도록 돕는 일반 안내이며, 특정 금액을 보장하지 않습니다. 계약·권리 처리는 사안에 따라 다르니 필요하면 전문가 상담을 권합니다.
