# 커버(첫 화면)에 이미지 넣기

> 배경: "인스타 첫 화면에 글만 있으니 글은 잘 띄는데 클릭률·뷰수가 떨어진다"(2026-07-27 피드백)
> → 커버에 **이미지 + 글**이 함께 들어가도록 카드뉴스·릴스 엔진을 확장했다.

## 확정 (2026-07-27)

- **형식 = A안 `full` (사진 전면 + 하단 글자).** 카드뉴스·릴스 공통. 엔진 기본값도 `full`.
- **사진 = 주제별로 새로 뽑는다.** 방법은 [`프롬프트팩_커버컷.txt`](프롬프트팩_커버컷.txt).
  생성한 컷은 `아트/`에 주제 슬러그 이름으로 저장해 재사용.
- 밝은 사진밖에 없을 때만 예외로 `split`(B안)을 쓴다. 글자가 배경에 먹히는 것보단 낫다.

## 시안 (`시안/`)

| 파일 | 설명 |
|---|---|
| `현재_글자만.png` | **지금까지의 방식** (비교용, 27_부가세 커버 원본) |
| `A_전면사진.png` | ★ 채택. 사진 전면 + 하단 글자 |
| `B_상하분할.png` | 위 사진 / 아래 글자 (밝은 사진용 예외) |
| `C_전면사진_다른컷.png` | A와 같은 형식, 사진만 교체 |
| `D_릴스_전면사진.png` | 릴스 9:16 A안 |
| `E_릴스_상하분할.png` | 릴스 9:16 B안 |
| `*_그리드확인.png` | 프로필 그리드 4:5 크롭선(빨간 점선)을 겹쳐 글자가 안 잘리는지 확인 |
| `_참고_gymcoding_그리드.jpg` | 참고로 받은 gymcoding 프로필 캡처 |

시안 사진은 사연 웹툰 아트를 임시로 갖다 쓴 것. 실제 발행분은 주제별 새 컷으로.

## 쓰는 법

`content.json`(카드뉴스)은 `cover`, `content_reel.json`(릴스)은 `hook` 슬라이드에 `img`만 추가.
**`img`가 없으면 지금까지의 글자만 커버 그대로**라 기존 덱은 영향 없다.

```json
{
  "type": "cover",
  "head": ["7월 부가세 신고,", "나도 대상일까?"],
  "hint": "마감 7월 27일(월) · 3.3% 프리랜서는 패스 👀",

  "img": "../_커버이미지/아트/tax_shock.png",
  "imgpos": "center 22%",
  "chip": "7월 27일 마감"
}
```

| 키 | 기본값 | 설명 |
|---|---|---|
| `img` | (없음) | 사진 경로. json 파일 위치 기준 상대경로 OK. 넣는 순간 이미지 커버가 된다 |
| `imgstyle` | `"full"` | `full`=사진 전면(기본) / `split`=위 사진·아래 글자 |
| `imgpos` | `center 30%` | 사진에서 보여줄 위치. **얼굴이 잘리면 % 를 낮춘다**(위쪽을 더 보여줌) |
| `imgsplit` | `56%`(릴스 `48%`) | split일 때 사진 높이 |
| `chip` | (없음) | 헤드라인 위 파란 태그 (카드뉴스 전용). 마감일·주제 라벨용 |
| `fitmax` | 자동 | 제목 최대 크기. 사진이 너무 가려지면 낮춘다 |

굽는 건 기존과 동일:
```
python ..\..\_작업스크립트\_gen_cardnews.py <덱>\content.json <덱>   →  _shot_deck.py <덱>
python ..\..\_작업스크립트\_make_reel.py <덱>                        →  릴스는 한 번에 mp4까지
```

## 만들 때 주의

- **제목은 3줄 이내, 짧게.** 사진 위에 얹는 순간 긴 제목은 읽히지도 않고 사진도 못 보여준다.
- **릴스 커버는 4:5 안쪽에.** 프로필 그리드에서 위아래 285px씩 잘린다. 엔진이 안쪽으로
  배치하지만 제목이 길면 다시 밀리니, 발행 전 `_그리드확인.png`처럼 한 번 확인.
- **밝은 사진은 글자가 죽는다.** 어두운 컷을 뽑는 게 기본. 프롬프트팩의 공통 스타일이
  "아래 1/3은 어둡고 단순하게"를 강제하는 이유.
- **비율을 맞춰서 뽑을 것 (릴스 9:16 / 카드 4:5).** 3:4 사진을 릴스 전면커버에 쓰면 좌우가
  잘리는 데다, 그 상태에선 `imgpos`의 세로 조정이 아예 먹지 않는다(높이 기준 스케일).
- **사진 안에 글자가 있으면 `full` 금지.** 하단 제목이 그 글자를 덮는다 → `split`으로.
  (실제 사고: 폭염 짤의 펀치라인이 제목에 완전히 묻힘)
- **`split`에 글이 많으면 사진 영역을 침범하지 않는지 확인.** 엔진이 `flex-start`로 아래로만
  밀리게 고쳐뒀지만, 칩·제목·서브를 다 넣으면 4:5 크롭선을 넘길 수 있다.
